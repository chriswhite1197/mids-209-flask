03 · The reveal

More Likes, Lower Match Rate—But About the Same Number of Matches

Match rate falls as likes received increase, while mutual matches remain nearly flat. Almost everyone ends up with about the same number of matches, around 15, no matter how many likes they get. So your match rate really just comes down to how many likes you received. If only a few people liked you, those matches look like a huge success rate. If hundreds liked you, the exact same matches look like a low one, even though you matched with just as many people.

Takeaway: Users end up with approximately the same number of mutual matches across most likes-received groups. Match rate falls primarily because the denominator grows, not because users receive fewer actual matches.

So a product manager who optimizes for match rate would be pushing users toward getting fewer likes, which is exactly backwards. Match rate is useful context, but it is not a metric to trust on its own. The final section outlines a more complete set of measures that keeps the actual user outcome—not just the ratio—in view.

Product implication: Before optimizing a percentage, check what is happening to both the numerator and denominator—and pair the ratio with the raw outcome users actually care about.

05 · In conclusion

Nothing predicts success here, and that is still useful

Across every trait we grouped by and every outcome we measured, nothing in this dataset predicts who succeeds on the app. A lot of that uniformity likely comes from the data being synthetic, so there may never have been a meaningful behavioral signal waiting to be found.

What usability testing taught us

One takeaway from our usability study was that the synthetic nature of the dataset made the findings feel less surprising and less actionable. Before selecting it, we explored multiple publicly available dating-app datasets, but we could not find an authentic source containing the combination of profile attributes, app behavior, likes received, and mutual matches needed for this analysis. These findings should therefore be treated as illustrative rather than as evidence of how real dating-app users behave.

Why the project still matters

The value isn’t the answer; it’s the setup. The metric check, interactive explorer, and broader outcome analysis form a reusable scaffold. Pointed at real dating-app data, a product manager could quickly see which levers move matches, which user groups behave differently, and whether the metric being reported is tracking meaningful success or just an illusion. We built the lens. Real data would fill in the picture.

What this means for product teams

Use match rate as context—not as the whole score.

A stronger measurement strategy combines the ratio with the raw outcome and the steps that lead to it. That makes it harder for a changing denominator to create a misleading success story.

01

Track the user outcome

Start with raw mutual matches so the metric reflects how many successful connections a user actually receives.

02

Keep the denominator visible

Review likes received alongside match rate so it is clear whether the percentage changed because attention changed.

03

Measure the full journey

Add the swipe-to-like-to-match funnel—and conversation or engagement quality when real product data makes it available.

Conversation and engagement quality are recommended next-step measures; they are not available in the current dataset.

Methods & limitations

Dataset

We analyzed 50,000 synthetic profiles from the Kaggle “Dating App Behavior” dataset. The records simulate behavior on a fictional dating app.

Primary metric

Match rate is calculated as mutual matches divided by likes received. We also examined raw likes received, mutual matches, swipe-right rate, and app-usage time.

Comparisons

We compared group averages across gender, age group, income bracket, relationship intent, activity, profile completeness, and interests.

Interpretation

This is descriptive analysis. The visualizations show associations and group averages; they do not establish that any trait or behavior causes a match outcome.

Key limitation: Because the dataset is synthetic, the uniform patterns may reflect how the data was generated rather than how real dating-app users behave. The findings illustrate the analytical framework; they should not be read as real-world dating behavior.
